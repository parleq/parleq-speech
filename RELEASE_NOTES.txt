Parleq 0.10.1

Small polish release. If you're on v0.10.0, this is the first
release Parleq's Sparkle auto-update will offer you — accepting
the prompt downloads + verifies + installs without you needing
to grab the .dmg manually.

### Added

- **Active microphone visible in three more places.**
  - The Microphone submenu's "System Default" entry now reads
    "System Default · <resolved name>" so the fallback isn't
    anonymous.
  - During dictation, the overlay's "listening…" line becomes
    "listening on <Mic Name>…" (and "listening for refinement
    on <Mic Name>…" during a refine pass) so you can confirm at
    a glance which device is being captured from.
  - Hovering the menu-bar Parleq icon when idle now surfaces a
    "Microphone: <full name>" tooltip.

  All three surfaces read from the same resolver, so the
  displayed name is always consistent. Closes #24.

## Install

If you're already running Parleq 0.10.0, Sparkle's update prompt
is the easiest path — it handles download, signature
verification, and the relaunch for you.

For a fresh install:

1. Download the .dmg attached to this release.
2. (Optional) Verify the SHA-256: `shasum -a 256 -c Parleq-0.10.1-<sha>.dmg.sha256`
3. Open the DMG and drag Parleq.app onto the Applications folder.
4. Eject the DMG, then launch Parleq from Applications.
5. On first launch, grant Microphone + Accessibility permissions
   and answer the auto-update prompt.

First launch downloads the speech model (~150 MB) — give it
30–60 seconds before pressing the hotkey. The menu-bar icon
switches from a download glyph to the bar mark when ready.

See README.md for hotkey, LLM provider setup (Gemini / Bedrock /
Vertex AI / Azure OpenAI), and custom-dictionary configuration.
