Parleq 0.10.0

First release with built-in auto-updates. From here on, you'll be
prompted to install new versions instead of needing to re-check
GitHub Releases manually.

### Added

- **Auto-updates via Sparkle.** Parleq now checks parleq.app on
  launch and once every 24 hours, and prompts you to install a
  newer version when one's available — the standard "an update
  is available" dialog familiar from most Mac apps. Each release
  is signed with an Ed25519 key whose public half ships inside
  every build, so a tampered update (or a tampered appcast file)
  is refused before any bytes touch your installed Parleq. Two new user-facing
  controls:
  - **Settings → Updates** — toggle "Automatically check for
    updates" on or off, plus a "Check for Updates Now" button.
  - **Menu bar → "Check for Updates…"** — on-demand check from
    the dropdown, useful when you want to grab a fresh release
    immediately without waiting for the next scheduled check.
- **First-launch update prompt.** The first time you launch this
  build, Sparkle asks "Would you like Parleq to check for updates
  automatically?" Pick whichever you prefer — Settings →
  Updates can change it any time.

### Compliance posture

The auto-update path adds two new outbound HTTPS calls, both
documented in docs/SECURITY_REVIEW.md §7a (Auto-update):

- Periodic GET of parleq.app/appcast.xml. Sparkle's User-Agent
  carries the app version and macOS version; nothing else.
- Per-install GET of the .dmg URL from
  github.com/parleq/parleq-speech/releases/download/...
  Fires only when the user accepts the update prompt.

Sparkle verifies every downloaded .dmg's Ed25519 signature
against the public key compiled into Parleq before installing.
Mismatch refuses the update.

## Install

1. Download the .dmg attached to this release.
2. (Optional) Verify the SHA-256: `shasum -a 256 -c Parleq-0.10.0-<sha>.dmg.sha256`
3. Open the DMG and drag Parleq.app onto the Applications folder.
4. Eject the DMG, then launch Parleq from Applications.
5. On first launch, grant Microphone + Accessibility permissions
   and answer the auto-update prompt.

First launch downloads the speech model (~150 MB) — give it
30–60 seconds before pressing the hotkey. The menu-bar icon
switches from a download glyph to the bar mark when ready.

See README.md for hotkey, LLM provider setup (Gemini / Bedrock /
Vertex AI / Azure OpenAI), and custom-dictionary configuration.
