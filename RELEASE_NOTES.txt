Parleq 0.11.1

Open-source attribution polish. v0.11.0 shipped on top of a
THIRD_PARTY_LICENSES.md that was last regenerated at v0.9.0 and
had drifted — most notably, Sparkle (added in v0.10.0 for
auto-updates) was missing from both THIRD_PARTY_LICENSES.md and
NOTICE. This release closes the gap. No code changes to dictation,
ASR, cleanup, or any user-visible workflow.

### Added

- **"Open Source Licenses…" item in the menu-bar dropdown.**
  Placed right after "About Parleq". Opens the canonical
  THIRD_PARTY_LICENSES.md on GitHub in your default browser —
  Markdown renders natively, and every upstream source repo is
  one click away. An offline copy is also bundled inside
  Parleq.app/Contents/Resources/.

- **LICENSE, NOTICE, and THIRD_PARTY_LICENSES.md ship inside the
  .app bundle now.** `make-app.sh` copies the three files into
  Parleq.app/Contents/Resources/ at build time. Discharges
  Apache-2.0 §4 (notice propagation on binary redistribution) and
  the MIT/BSD attribution clauses for Sparkle and its vendored
  components, without relying on downstream redistributors to
  also ship a separate notice file alongside the .dmg.

### Changed

- **THIRD_PARTY_LICENSES.md and NOTICE refreshed.** Sparkle 2.9.1
  (MIT) is now credited as a direct dependency, along with its
  two vendored components — ed25519-sparkle (zlib-style) and
  bsdiff (2-clause BSD) — that ship inside Sparkle.framework.
  The obsolete Hummingbird section was removed (it was retired
  in v0.9.0). FluidAudio version refreshed 0.14.3 → 0.14.5
  (within the pinned range). At-a-glance counts updated;
  audit-trail footer dated to v0.11.0. External-services list
  extended to include Vertex AI, Azure OpenAI, and the Sparkle
  appcast as runtime egress destinations alongside the
  previously-listed Gemini, Bedrock, Hugging Face, and GitHub.

- **About page on parleq.app gets a body link** to
  THIRD_PARTY_LICENSES.md in addition to the existing footer
  link, naming the heavyweight deps by category for quick
  orientation.

## Install

If you're already running Parleq 0.11.0, Sparkle's update prompt
is the easiest path — it handles download, signature
verification, and the relaunch for you. (This is the first
release whose installed .app physically carries the bundled
LICENSE / NOTICE / THIRD_PARTY_LICENSES.md files inside
Contents/Resources/, so updating from 0.11.0 is what gets you
the bundled attribution.)

For a fresh install:

1. Download the .dmg attached to this release.
2. (Optional) Verify the SHA-256: `shasum -a 256 -c Parleq-0.11.1-<sha>.dmg.sha256`
3. Open the DMG and drag Parleq.app onto the Applications folder.
4. Eject the DMG, then launch Parleq from Applications.
5. On first launch, grant Microphone + Accessibility permissions
   and answer the auto-update prompt.

First launch downloads the speech model (~150 MB) — give it
30–60 seconds before pressing the hotkey. The menu-bar icon
switches from a download glyph to the bar mark when ready.

See README.md for hotkey, LLM provider setup (Gemini / Bedrock /
Vertex AI / Azure OpenAI), and custom-dictionary configuration.
