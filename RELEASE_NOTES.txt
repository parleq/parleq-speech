Parleq 0.9.1

Polish release on top of v0.9.0's in-process consolidation. Two
visible improvements; no behavior change to dictation.

### Added

- **Real progress bar in the initialization overlay.** If you press
  the dictation hotkey before the speech model has finished loading,
  the overlay now shows a linear progress bar with a phase label
  ("Downloading speech model (N of M)…", "Compiling joint-decoder.mlmodelc…",
  etc.) instead of a generic indeterminate spinner. You'll mainly
  see this on first launch, when the ~150 MB Parakeet TDT v3
  download is in flight — on a slow connection the old spinner read
  as "the app is frozen." If you don't try to dictate during init,
  you won't see this UI at all. Closes #15.

### Changed

- **DMG mounts with the Parleq icon.** When you download the .dmg
  and mount it, the volume on the desktop / in the Finder sidebar
  now renders with the five-bar Parleq mark instead of the generic
  disk-image glyph.

## Install

1. Download the .dmg attached to this release.
2. (Optional) Verify the SHA-256: `shasum -a 256 -c Parleq-0.9.1-<sha>.dmg.sha256`
3. Open the DMG and drag Parleq.app onto the Applications folder.
4. Eject the DMG, then launch Parleq from Applications.
5. On first launch, grant Microphone + Accessibility permissions.

First launch downloads the speech model (~150 MB) — give it
30–60 seconds before pressing the hotkey. The menu-bar icon
switches from a download glyph to the bar mark when ready.

See README.md for hotkey, LLM provider setup (Gemini / Bedrock /
Vertex AI / Azure OpenAI), and custom-dictionary configuration.
