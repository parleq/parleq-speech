Parleq 0.42.0

Choose your on-device model, and voiceprints that hold up in real sentences.

On-device cleanup now offers a model choice. Keep the default Gemma 4 E4B for the best quality, or switch to the lighter Qwen3-4B — roughly half the download and memory, so full on-device LLM cleanup now fits on an 8 GB Mac. Choose one under Settings → Cleanup → Provider → On-device, or in the setup wizard. Either way, cleanup runs entirely on your Mac.

Voiceprints hold up in real sentences. If you've enrolled a term that sounds like an everyday word, Parleq no longer trips over it mid-sentence — an enrolled "Keavi" stays "Keavi" even when you say "kiwi" later in the same sentence, because the acoustic gate now judges each word from its own audio. And when it keeps a term with only borderline confidence, the review overlay flags it so a one-tap edit fixes and teaches it.

Cleanup settings are clearer. The overlay now tells you which cleanup mode ran and why — including when an app uses a built-in default (terminals and code editors stay on fast on-device cleanup so your commands aren't sent to an LLM). Those defaults are visible and overridable in Settings → App behaviors, and on-device model names now show cleanly and correctly throughout.
