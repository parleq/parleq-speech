Parleq 0.11.0

Cleanup-failure recovery across all three cloud providers. When
a cloud sign-in expires mid-session (`aws sso login` token,
`gcloud` ADC, Azure Entra ID), Parleq now picks up the refreshed
credentials on the next dictation without a restart. Three new
surfaces (overlay hint, menu-bar badge, Recent Dictations
annotation) tell you exactly what happened and how to fix it.

### Added

- **Auto-refresh credentials on auth failure for Bedrock SSO,
  Vertex ADC, and Azure Entra ID.** Previously if you launched
  Parleq with an expired cloud session and then re-logged in
  externally (`aws sso login` / `gcloud auth application-default
  login` / `az login`), Parleq stayed stuck on the stale token
  and pasted raw ASR until you quit and relaunched. Each
  provider's streaming call now retries once on auth failure
  after invalidating its in-memory token cache — picking up the
  fresh credentials from the CLI's own cache. 403s (IAM
  denials) deliberately not retried. Closes #26, #30.

- **Recovery hint in the accept overlay.** When LLM cleanup
  fails and Parleq falls back to raw ASR, the overlay footer
  carries the exact one-liner you need to run — e.g. "Run `aws
  sso login --profile work`, then dictate again." Closes #27
  (overlay hint).

- **Menu-bar badge for cleanup failures.** Quick mode has no
  overlay to surface the failure inline, so the status icon
  goes amber and a dismissable "⚠ Cleanup failed — <hint>" row
  appears in the dropdown. Fires for every dictation (either
  mode), so a successful subsequent cleanup auto-clears the
  badge even if you never dismissed it manually. Closes #28.

- **Recent Dictations marks raw-fallback entries.** Entries
  whose cleanup failed get a trailing ` · raw` suffix in the
  Recent Dictations submenu, with a tooltip spelling it out.
  Useful for spotting which dictations are worth re-running
  with cleanup working again. Closes #27.

## Install

If you're already running Parleq 0.10.x, Sparkle's update
prompt is the easiest path — it handles download, signature
verification, and the relaunch for you.

For a fresh install:

1. Download the .dmg attached to this release.
2. (Optional) Verify the SHA-256: `shasum -a 256 -c Parleq-0.11.0-<sha>.dmg.sha256`
3. Open the DMG and drag Parleq.app onto the Applications folder.
4. Eject the DMG, then launch Parleq from Applications.
5. On first launch, grant Microphone + Accessibility permissions
   and answer the auto-update prompt.

First launch downloads the speech model (~150 MB) — give it
30–60 seconds before pressing the hotkey. The menu-bar icon
switches from a download glyph to the bar mark when ready.

See README.md for hotkey, LLM provider setup (Gemini / Bedrock /
Vertex AI / Azure OpenAI), and custom-dictionary configuration.
