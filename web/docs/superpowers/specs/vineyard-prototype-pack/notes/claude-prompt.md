Context:

The main homepage hero direction is already mostly settled elsewhere. Do not redesign the entire homepage from scratch. Focus on the sections after the hero, especially the grape explorer and the privacy/vineyard section.

Design goal:

Create a premium, restrained, indie-Mac-app style grape explorer that replaces a long feature grid with a compact interactive section.

Preferred direction:

- Use Prototype B as the main structural inspiration.
- Borrow restraint and overlay treatment from Prototype A.
- Borrow only the subtle boundary/gate idea from Prototype C.
- Avoid copying literal leaves/tendrils, realistic fruit texture, or decorative vineyard scenery.

Important constraints:

- Keep feature names literal.
- Do not rename product features into metaphor language.
- Do not make the site kitschy.
- Do not use wine/farm/cartoon imagery.
- Do not over-brand Concord; treat it as attribution only if mentioned.
- Voiceprints distinguish sound-alike words; do not describe them as learning the user’s style/rhythm.
- “Your voice never leaves your Mac” is safe.
- Avoid blanket “nothing leaves your Mac” claims unless scoped carefully.

Implementation preference:

Desktop grape explorer should use a split-stage interaction:

- left: grape clusters
- right: active demo panel
- selected grape sends amber/violet flow lines to demo panel

Mobile should use a simplified tab/accordion interaction.

Please use the notes as design direction, not as final copy.
